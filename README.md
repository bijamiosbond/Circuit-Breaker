# CIRCUIT BREAKER

A neon PCB-themed arcade game built with **Python** and **Pygame**.

Navigate your signal through a circuit board, avoid electronic obstacles, and reach the destination USB port without crashing.

## Gameplay

- Control a continuously moving signal.
- Move in four directions: up, down, left and right.
- Turn whenever you want.
- Avoid walls and PCB obstacles.
- Reach the destination USB port to complete the level.

## Controls

| Key | Action |
|---|---|
| ↑ | Move up |
| ↓ | Move down |
| ← | Move left |
| → | Move right |

You cannot directly reverse direction.

## Features

- Neon PCB-inspired visuals
- Continuous movement
- Collision detection
- Glowing player trail
- Win and Game Over screens
- Restart functionality
